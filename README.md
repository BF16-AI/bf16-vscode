# bf16.ai VS Code / Cursor / Windsurf Extension

Quickly inspect live 1M-context uncensored LLM pricing from `https://api.bf16.ai/v1/models` and copy zero-touch agent configs (`npx bf16ai`) inside VS Code, Cursor, or Windsurf.

Download `.vsix` builds from [GitHub Releases](https://github.com/BF16-AI/bf16-vscode/releases) or explore [bf16.ai](https://bf16.ai).
